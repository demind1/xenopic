# NIGHTFRAME Studio · 0.1

Первый этап офлайн-видеоредактора музыкальных эдитов для Windows 10/11 x64. Это развиваемый MVP, а не завершение всей долгосрочной спецификации. Интерфейс на русском, тёмная биомеханическая палитра, оригинальная процедурная графика. Приложенные художественные референсы не включены в приложение.

## Запуск разработчиком

Node.js 22 LTS (не ниже 22.12), npm. В существующем checkout:

```sh
npm ci
npm test
npm run desktop
```

`npm run dev` запускает браузерную версию Vite на 5173: можно проверить интерфейс, импорт файлов, монтаж и Canvas-предпросмотр. MP4-экспорт, файловые диалоги и постоянные ссылки на локальные медиа работают в Electron. В браузере это явно обозначено. `npm run desktop:dev` требует отдельно работающий Vite. В облачной среде используются существующий checkout и штатный HTTPS-прокси, без дополнительных worktree. `postinstall` устанавливает Electron 45 заранее для офлайн-запуска, используя штатный прокси и undici EnvHttpProxyAgent, когда proxy уже настроен. Проверка официальных контрольных сумм остаётся включённой.

## Быстрый монтаж

1. Нажмите «Новый», затем «Импортировать» или перетащите видео/музыку в окно. Файлы сразу добавляются в медиатеку и на таймлайн в позиции курсора. Повторно добавить файл можно двойным щелчком в медиатеке.
2. Перемещайте клипы и их края мышью. В инспекторе можно точно задать начало, длительность и отступ в исходнике. Кнопка ножниц / S разделяет выбранный клип в позиции курсора. Исходные файлы не изменяются.
3. Выделите клип и нажмите эффект или пресет слева. Настройте интенсивность справа. Эффекты комбинируются; крестик удаляет эффект. Поиск принимает русские и английские названия.
4. В разделе «Текст» добавьте надпись; измените её справа. Положение выбранного визуального слоя можно менять на превью. «Ключевые кадры» раскрывают анимацию X/Y, масштаба и прозрачности: выберите время, задайте значение и нажмите ромб.
5. Настройки сверху задают 16:9 / 9:16 / 1:1 / 4:5 / 21:9 и 24/30/60 FPS. Сохраните `.nightframe`. Медиа остаются по исходным путям, их нельзя удалять или перемещать. Проект с отсутствующим медиа выдаёт ошибку.
6. «Экспортировать» → 720p/1080p, FPS и качество → выбор папки. Композиция рендерится покадрово, звук сводится FFmpeg в AAC, видео — H.264 MP4. Отмена завершает процесс и удаляет временный файл. Готовый файл проверяется через FFprobe.

Space — play/pause; S — split; Delete — удалить; Ctrl+D — дублировать; Ctrl+Z / Ctrl+Shift+Z — undo/redo; Ctrl+S — сохранить; M — ручной beat-маркер. Клавиши не перехватываются в полях ввода. Маркеры удаляются нажатием. Дорожки можно отключать и блокировать. Есть привязка к краям клипов и маркерам, масштабирование и прокрутка таймлайна, реальная waveform, регулировка громкости и локальное автосохранение с восстановлением. Никаких аккаунтов и телеметрии.

## Архитектура

- `electron/main.ts`: медиапроба, доверенные файловые диалоги, ограниченный media-протокол с Range, сохранение, lifecycle FFmpeg.
- `electron/preload.ts`, `src/core/bridge.ts`: типизированный минимальный IPC; context isolation, sandbox, Node отключён в renderer, валидация отправителя.
- `src/core/model.ts`: версионированный Zod-граф композиции, эффекты, пресеты, интерполяция, nondestructive split.
- `src/core/store.ts`: монтажное состояние Zustand, undo/redo.
- `src/render/compositor.ts`: общий Canvas-рендерер предпросмотра и офлайн-кадров. Seeded grain зависит от номера кадра, не случайного времени.
- `src/core/media.ts`: браузерный импорт, декодирование waveform через Web Audio.
- `src/components`: медиатека/эффекты, плеер, инспектор, многодорожечный таймлайн.

Сохранение — JSON с валидацией схемы и атомарным переименованием временного файла. Экспорт — последовательный поток JPEG-кадров с backpressure в FFmpeg, ограниченная память. Аудиомикс учитывает trim, start, volume и mute каждого аудио/видеоклипа. Геометрия, эффекты и анимация не реализуются второй раз в FFmpeg: кодируется именно результат Canvas-композитора. Снижение качества предпросмотра не влияет на разрешение экспорта.

## Проверки и Windows

```sh
npm test
npm run build
npm run test:e2e
npm run dist:win
```

Playwright создаёт собственные синтетические видео и WAV, запускает браузер и настоящий Electron, импортирует медиа, проверяет waveform, сохранение/открытие, монтаж и MP4 H.264/AAC через FFprobe. `test-results/` содержит визуальные артефакты; `.local/output.mp4` — тестовый экспорт. Linux desktop-test требует X-сервер (например Xvfb или Xorg dummy) и использует `--no-sandbox` только для тестового запуска в контейнере; производственное приложение sandbox не отключает. При необходимости `NIGHTFRAME_CHROMIUM` задаёт локальный Chromium. `NIGHTFRAME_FFMPEG` и `NIGHTFRAME_FFPROBE` — developer-only overrides установленных инструментов; конечному пользователю они не нужны.

`.github/workflows/windows.yml` запускает проверки и собирает NSIS `.exe` на `windows-latest`. Workflow нужно запустить в GitHub; локальная Linux-проверка не подтверждает установку на Windows. Конечный пользователь устанавливает `.exe` без Node/Python/FFmpeg. Бинарники поставляются electron-builder через `asarUnpack`, notices — через `extraResources`. См. [лицензии и ограничения распространения](docs/THIRD_PARTY.md).

## Текущие ограничения

- Реализованы 8 базовых эффектов: Brightness, Contrast, RGB Split, Pixelation, Film Grain, Divine Glow, Monochrome и Fade. Четыре быстрых пресета состоят из этих работающих эффектов. Fade — визуальный, аудиофейды пока не поддерживаются.
- Canvas2D, не WebGL2: высокая нагрузка на длинных/1080p60 проектах; GPU shaders, прокси и renderer worker — следующие этапы. Плавные 60 FPS не гарантируются. Аудио в preview синхронизируется с допуском 160 ms; экспорт использует точные таймкоды. Это не sample-accurate audio workstation.
- Форматы preview зависят от декодеров Electron/Chromium. Неподдерживаемые контейнеры/кодеки могут пройти FFprobe, но выдать явную ошибку декодирования; автоматического транскодирования пока нет.
- Для анализа waveform desktop декодирует до первого часа аудио; очень длинные файлы требуют потокового кэша. Нет автоматического beat detection / FFT audio-reactive, масок, blend modes, переходов (кроме fade), Xenomorph Visual Pack, сложной типографики, импорта шрифтов и редактируемых Bezier-кривых.
- Панели пока фиксированы по ширине. Нет групп клипов и пользовательского aspect ratio. Блокировка/отключение дорожек и до 16 дорожек поддерживаются.
- Автосохранение хранится локально, медиа не копируются. Для переноса на другой компьютер нужно сохранить исходники с корректными путями; media relink ещё не реализован.
- Установщик без подписи; Windows install/uninstall, HiDPI, 30-секундный реальный FL Studio-проект 1080p60 и длительная стабильность требуют отдельной проверки на Windows. Не заявляются проверенными до запуска соответствующих проверок.

План развития и результаты проверок: [docs/STATUS.md](docs/STATUS.md).

В этой облачной Linux-среде `npm run test:cloud` поднимает существующий Xorg dummy при отсутствии DISPLAY и выполняет E2E. Скрипт завершает только созданный им X-сервер. Для обычного Windows-разработчика этот шаг не нужен.

Для проверки уже упакованного Linux-приложения: `NIGHTFRAME_PACKAGED_APP="$PWD/release/linux-unpacked/nightframe-studio" npm run test:cloud`. Этот сценарий также проверен; он использует исполняемые файлы из `app.asar.unpacked`, а не developer overrides.
