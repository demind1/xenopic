# Distribution and resources

Application source and original procedural artwork: MIT (LICENSE). No supplied reference images, copyrighted characters, external fonts or sample recordings are embedded. UI fonts use the operating system; Lucide icons use ISC. React and Zustand are MIT; Electron carries MIT and Chromium third-party notices. Undici is a development-only HTTP proxy adapter for the official Electron downloader; it does not introduce a runtime service. Zod validates data at the process boundary; Lucide supplies consistent accessible icons. No server, analytics, account system or online runtime dependency is included.

Media dependencies are separate executables: ffmpeg-static (downloaded by its upstream installer from eugeneware/ffmpeg-static GitHub releases), ffprobe-static (binaries inside the npm distribution; upstream build provenance is described in its README). npm lockfile verifies npm package integrity. Electron's installer verifies its release checksums. Use TLS and the session's CA/proxy; never disable verification.

FFmpeg binaries containing libx264 are GPL builds, not covered by this application's MIT license. Bundled notices are copied at build time into resources/notices, along with upstream README/provenance and package metadata. FFmpeg's license and corresponding-source obligations apply to distributing those binaries. Before public redistribution, retain the exact binary versions/build configuration and make corresponding source and build scripts available under their applicable licenses. The old ffprobe-static upstream build requires a provenance/source audit or replacement with a maintained, verifiable build before a public release. The CI artifact is a development, unsigned installer; this repository does not claim public release license clearance or codec patent clearance.

Projects reference original local files; they do not embed or distribute user media. Users retain responsibility for rights to their own media and fonts. No online asset library is contacted.
